# CloudDocs — Full DevOps Pipeline on AWS

This project is my first complete DevOps pipeline deployed on AWS using real cloud infrastructure and Kubernetes orchestration.

It covers the complete deployment lifecycle of a modern cloud-native application, including:

- Dockerized frontend and backend services
- AWS ECR image management
- AWS EKS Kubernetes cluster deployment
- Kubernetes deployments, services, and ingress
- PostgreSQL integration
- Public cloud deployment with AWS Load Balancer
- Debugging real-world deployment and infrastructure issues

The project was deployed and tested on a live AWS environment instead of a local-only setup.
